## v2.1.1 — Bot engine foundation

- Upgraded the WPF client to .NET 8 for Windows x86.
- Added a bot state machine: Idle, Target, Approach, Fight, Loot, and Rest.
- Added the Bot tab with Start/Stop controls, current state, and a bounded log.
- Added a CI build check for pushes and pull requests.

The engine is a skeleton in this version: it logs state transitions without sending autonomous game commands. Target selection and approach follow in day 3; combat follows in day 4.

Download `L2Bot-win-x86.zip` under **Assets**, extract it, and run `Client.exe` on Windows. The archive includes the client, DLLs, and 165 geodata regions.

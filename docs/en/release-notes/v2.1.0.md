## v2.1.0 — Geodata and release packaging

- Bundled 165 Interlude geodata regions for pathfinding.
- Added a startup check and downloader for missing geodata, with progress and cancellation.
- Automated Windows x86 release builds, including the native geodata pathfinder.
- Added English and Russian setup documentation.

Download the ZIP under **Assets**, extract it, and run `Client.exe` on Windows. The archive contains the WPF client, bot DLL, native pathfinder, and geodata. This release provides manual control and the foundation for the autonomous bot roadmap.

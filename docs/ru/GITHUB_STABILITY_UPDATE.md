# Обновление стабильности — транспорт, жизненный цикл и сборка

Актуальная база документации: **v2.1.4**, обновлено 2026-11-10.

## Платформа и сборка

- WPF-клиент использует **.NET 8** (`net8.0-windows`) и **x86**.
- Инжектируемая DLL и нативные библиотеки собираются в **Release | Win32** для поддерживаемого 32-битного клиента Lineage 2 Interlude. Наличие конфигураций x64 в проектах не подтверждает поддержку 64-битного игрового runtime.
- Результат сборки находится в `Release\bin\` в корне репозитория.
- `build.yml` запускает регрессионные проверки и собирает нативную DLL и WPF-клиент на Windows. `release.yml` дополнительно собирает нативный pathfinder и упаковывает релиз Windows x86 с геодатой.
- Архив релиза: `L2Bot-win-x86.zip`. Требования и порядок сборки описаны в [SETUP](SETUP.md).

## Подключение и синхронизация

- Клиент удаляет перенос строки из имени pipe при handshake, сериализует записи и собирает полные сообщения перед разбором.
- `Invalidate` передаётся командой в JSON. Каждая сессия очищает состояние клиента и получает полный снимок с героем в начале.
- Повторная синхронизация сохраняет событийные кеши предметов, навыков и баффов DLL. Повторный create обновляет существующую сущность клиента.
- Названия полей и строковые значения JSON экранируются.
- Обновления репозиториев и сериализация снимков используют общую рекурсивную блокировку состояния мира. Сроки каста и отката навыков больше не зависят от фоновых потоков таймеров.

## Runtime и поведение клиента

- Инжектированный runtime остаётся загруженным до закрытия игры. Выгрузка DLL не ждёт рабочий поток под loader lock Windows.
- Трамплины хуков используют исполняемую память и очистку кеша инструкций. При перечислении потоков используются правильные размер структуры и фильтр процесса.
- Ошибки запуска подключения видны в клиенте, удалённые view model освобождают подписки, история чата ограничена.
- Вытесненные маршруты прекращают повторные попытки. Инвентарь различает типы экипировки, изменения автозарядки сосок передаются клиенту, для баффов добавлены модели и вкладка Buffs.

## Проверки и ограничения

В журнале работ v2.1.3 зафиксирован успешный Windows CI: нативные регрессионные проверки, рабочие команды C# через C++ парсер и диспетчер, настоящий handshake named pipe, повторная синхронизация, переподключение, остановка и сборка нативной части/WPF под x86. Это результаты того релиза; текущие локальные проверки Windows описаны в заметках v2.1.4 ниже.

Живая проверка Interlude ещё требуется для смещений игровых структур, пятибайтовых хуков и внешнего pathfinder. Для выгрузки инжектированного runtime закройте игру. Проверка геодаты при запуске по-прежнему требует онлайн-запроса; прерванный файл скачивается заново при следующем запуске.

Движок выбирает цель, подходит, повторяет базовые атаки и временно исключает недостижимые или зависшие цели. Stop отменяет ожидающие записи команд бота и запрашивает прерывание действия; смерть героя или отключение останавливает движок. Подтверждённая смерть цели переводит в `Loot`, автоматический подбор запланирован на день 5 [дорожной карты](ROADMAP.md).

Подробный список изменений — в [описании v2.1.3](release-notes/v2.1.3.md).

Настройки боя, локальные проверки Windows и текущие ограничения описаны в [заметках v2.1.4](release-notes/v2.1.4.md).

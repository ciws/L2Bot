# Обновление стабильности — транспорт, жизненный цикл и сборка

## Кратко
Это обновление посвящено стабильности во время выполнения, безопасному завершению работы и переносимости сборки смешанного C++/C# решения.

Основные цели:
- Устранить опасные зависания при завершении работы и подверженное дедлокам поведение при запуске.
- Добавить явную отмену и управление переподключением на стороне C#-клиента.
- Усилить обмен по именованному каналу при разрывах/переподключениях и остановке.
- Сделать сборку проектов надёжной в конфигурациях `x86` и `x64`.

## Ключевые улучшения

### Стабильность C#-клиента
- Жизненный цикл бота переработан с `async void` fire-and-forget на отменяемый поток на задачах.
- Добавлены контролируемые запуск/остановка в WPF `App` и корректная остановка бота при выходе.
- Транспортный API стал поддерживать отмену (`ConnectAsync`, `StartReceiveAsync`, `SendAsync`).
- Усилены рукопожатие/чтение по именованному каналу и проверки освобождения ресурсов.
- Исправлен баг busy-spin в движении по пути (`Task.Delay` без await в синхронном цикле).
- Улучшена видимость ошибок отправки — асинхронные сбои теперь логируются.

### Стабильность C++-рантайма
- Добавлен хук остановки транспорта и сигнал остановки перед join рабочих потоков.
- Координация флага остановки переведена на атомики в потоках обработчика мира.
- Циклы ожидания overlapped I/O именованного канала переработаны, чтобы не блокироваться бесконечно при остановке.
- Добавлен явный поток остановки/отмены для именованных каналов (`CancelIoEx` + сигнал через событие).
- Исправлена обработка граничных случаев overlapped `ConnectNamedPipe` при подключении.
- Тяжёлая инициализация и teardown вынесены из `DllMain` в рабочий поток для снижения риска loader-lock.

### Сборка и переносимость
- Абсолютные пути include заменены на относительные.
- Добавлены недостающие настройки стандарта языка и include-директории для x64.
- Исправлены несоответствия конфигурации precompiled headers для x64.
- Обновлён C# `Directory.Build.Props`, чтобы не зависеть строго от `$(SolutionDir)` при сборках через CLI.

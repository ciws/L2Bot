## v2.1.4 — Бой и антизастревание (день 4)

- Добавлены автоматические базовые атаки после подхода к живому враждебному NPC, с настраиваемым интервалом повторения.
- Добавлен таймаут подхода, который сохраняется при пересчёте маршрутов. Неудачный маршрут или таймаут временно исключает цель, чтобы бот мог выбрать другого моба.
- Добавлен таймаут прогресса боя: новый минимум наблюдаемого HP цели обновляет срок ожидания. При отсутствии прогресса цель временно исключается; одно лишь лечение цели не продлевает ожидание.
- Подтверждённая смерть цели переводит движок в `Loot`; исчезновение без подтверждённой смерти возвращает к поиску. Подбор лута остаётся задачей дня 5.
- Stop отменяет ожидающие записи команд бота. При выходе из боя отправляется движение в текущую позицию героя для прерывания действия. Смерть героя, потеря соединения или смена сессии героя останавливает движок; для продолжения нужно нажать Start.
- Актуализирована документация окружения Windows, из репозитория удалены служебные файлы Finder.

### Настройки

Измените `config.json` и перезапустите клиент:

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `AttackIntervalSeconds` | 1 | Минимальный интервал запросов атаки; проверяется на такте движка 500 мс |
| `ApproachTimeoutSeconds` | 15 | Максимальное время одного подхода, включая пересчёты маршрута |
| `CombatProgressTimeoutSeconds` | 20 | Максимальное время без нового минимума наблюдаемого HP цели |
| `TargetCooldownSeconds` | 30 | Временное исключение после ошибки маршрута или таймаута |

Интервалы должны быть положительными, конечными и не превышать 86400 секунд. Используются существующие `TargetSearchRadius` и `TargetApproachDistance`; доступны базовые атаки без ротации навыков, автоматического лута, банок и отдыха.

### Проверки и ограничения

Локальные проверки Windows покрывают нативные регрессии, выбор цели и движение, повтор атак, прогресс HP, смерть цели, отмену ожидающей записи атаки, отключение, смерть героя, таймауты подхода и боя, исключение целей и его истечение, а также настоящий протокол C# → C++ через named pipe. WPF-клиент и Win32 DLL/Core также собираются локально. GitHub Actions повторяет проверки перед упаковкой релиза.

Живая проверка Interlude ещё требуется. Остановка отправляет запрос прерывания, но его фактическое действие, смещения структур, хуки и внешний поиск пути нужно проверить с поддерживаемым игровым клиентом. Сам нативный поиск пути прервать нельзя; отменённый поиск после возврата не отправляет новый маршрут. Для выгрузки инжектированного runtime закройте игру.

Скачайте `L2Bot-win-x86.zip` в разделе **Assets**, распакуйте и запустите `Client.exe` в Windows. Клиент, DLL и 165 регионов геодаты включены.

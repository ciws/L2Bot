## v2.1.3 — Исправления подключения и выполнения

- Исправлен handshake: клиент убирает перенос строки из имени pipe, присланного сервером. Записи клиента сериализованы, фрагменты сообщений собираются перед разбором.
- Исправлены формат команды `Invalidate` и синхронизация после переподключения. Состояние клиента очищается перед сессией, DLL отправляет полный снимок с героем в начале. Кеши навыков, предметов и баффов сохраняются при повторной синхронизации; повторный create обновляет существующую сущность.
- Исправлено экранирование JSON для имён, чата, описаний и названий полей.
- Исправлены размер структуры перечисления потоков и фильтр процесса при установке хуков.
- Неработающие блокировки репозиториев заменены общей рекурсивной блокировкой состояния мира, включая сборку снимков и обработку событий. Сроки каста и отката навыков обрабатываются без фоновых потоков таймеров; чужие касты больше не блокируют навыки героя.
- Исправлены выключение автозарядки сосок, обнаружение изменений и проверка типа предмета.
- Добавлены модели баффов, обработка и вкладка Buffs. Инвентарь различает расходники, броню, оружие и щиты, обновляет описания/количество и даёт фактическую сумму адены.
- Исправлены повторы отменённых маршрутов, освобождение подписок удалённых объектов карты/целей, ограничена история чата, добавлено сообщение об ошибке запуска подключения.
- Инжектированный runtime закреплён на время игровой сессии. Выгрузка DLL больше не ждёт рабочий поток под loader lock Windows; трамплины хуков размещаются в исполняемой памяти с очисткой кеша инструкций.

### Проверки

Нативные проверки покрывают JSON, автозарядку, повторную отправку полного снимка и синхронизацию. Настоящие команды C# проходят через рабочий C++ парсер и диспетчер команд. Windows CI также проверяет настоящий handshake named pipe, повторную синхронизацию, переподключение и остановку, затем собирает DLL x86 и WPF-клиент.

Проверка в живом Interlude ещё требуется: смещения структур и пятибайтовые хуки остаются привязаны к поддерживаемому клиенту. Для выгрузки инжектированного runtime закройте игру. Автобой остаётся следующим этапом роадмапа; этот релиз не добавляет атаки.

Скачайте `L2Bot-win-x86.zip` в разделе **Assets**, распакуйте и запустите `Client.exe` в Windows. Клиент, DLL и 165 регионов геодаты включены.

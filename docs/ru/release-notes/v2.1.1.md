## v2.1.1 — Основа движка бота

- WPF-клиент переведён на .NET 8 для Windows x86.
- Добавлен конечный автомат: Idle, Target, Approach, Fight, Loot и Rest.
- Добавлена вкладка Bot: Start/Stop, текущее состояние и лог с ограничением числа строк.
- Добавлена проверка сборки CI на пуши и pull request.

В этой версии движок — каркас: он логирует переходы состояний и не отправляет автономные игровые команды. Выбор цели и подход запланированы на день 3, бой — на день 4.

Скачайте `L2Bot-win-x86.zip` в разделе **Assets**, распакуйте и запустите `Client.exe` в Windows. В архиве: клиент, DLL и 165 регионов геодаты.

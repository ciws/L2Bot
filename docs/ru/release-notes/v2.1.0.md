## v2.1.0 — Геодата и сборка релизов

- В архив включены 165 регионов геодаты Interlude для поиска пути.
- Добавлены проверка геодаты при запуске и загрузка отсутствующих файлов с прогрессом и отменой.
- Автоматизирована сборка релизов Windows x86, включая нативную библиотеку поиска пути.
- Добавлены инструкции по установке на русском и английском.

Скачайте ZIP в разделе **Assets**, распакуйте и запустите `Client.exe` в Windows. В архиве: WPF-клиент, DLL бота, библиотека поиска пути и геодата. Релиз предоставляет ручное управление и основу для дальнейшей автоматизации по роадмапу.

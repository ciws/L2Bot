# Дорожная карта L2Bot — 10 дней

**[English version](../en/ROADMAP.md)**

Цель: превратить клиент из «радара с ручным управлением» в настоящего бота с автономным циклом фарма. Каждый день заканчивается осмысленным коммитом(ами) в `master`. Каждый пуш проверяется сборкой в GitHub Actions.

Обозначения: 🖥 C# клиент • 💉 C++ DLL • 🔧 инфраструктура

## День 1 — Фундамент: .NET 8 + CI-проверка сборки 🔧
- Апгрейд клиента `net6.0-windows` → `net8.0-windows` (6-я версия вне поддержки)
- Workflow `build.yml`: сборка всего решения на каждый пуш в master (без релиза)
- Зачистка ворнингов клиента
- **Коммит:** `build: net8 + ci build check on every push`

## День 2 — Скелет движка бота 🖥
- `BotEngine`: конечный автомат `Idle → Target → Approach → Fight → Loot → Rest`
- Кнопка Start/Stop в главном окне, индикатор текущего состояния
- Пока без логики — только каркас и переходы-заглушки
- **Коммит:** `feat: bot engine state machine skeleton + start/stop ui`

## День 3 — Выбор цели 🖥
- Поиск ближайшего моба в радиусе через `WorldHandler` (фильтры: NPC/моб, живой, не в бою с другим)
- Настройка радиуса в `config.json`
- Подход к цели через `AsyncPathMover` по геодате
- **Коммит:** `feat: target selection and approach`

## День 4 — Бой 🖥
- Цикл атаки до смерти цели, таймауты
- Антизастревание: цель недостижима N секунд → следующая
- Переход `Fight → Loot` по событию смерти
- **Коммит:** `feat: combat loop with anti-stuck`

## День 5 — Лут 🖥
- Подбор дропа в радиусе после килла (события `DropCreatedEvent`)
- Приоритет: ближайший дроп первым
- **Коммит:** `feat: looting after kill`

## День 6 — Отдых и расходники 🖥
- Sit при HP/MP ниже порога, Stand при восстановлении
- Автобанки HP/MP по порогам (`RequestUseItem`)
- Пороги в `config.json`
- **Коммит:** `feat: rest and potion conditions`

## День 7 — Бафф-ватчер 🖥
- Таймерная перебаффовка селф-баффов (`RequestUseSkill` по расписанию)
- Список баффов и их длительность в конфиге
- **Коммит:** `feat: buff watcher`

## День 8 — Панель настроек 🖥
- UI-вкладка настроек бота (радиус, пороги, баффы, списки)
- Сохранение профилей в JSON
- **Коммит:** `feat: bot settings panel with json profiles`

## День 9 — Смерть и безопасность 🖥
- Детект смерти → остановка движка + громкий лог
- Опция «остановиться» / «ждать ресса»
- Улучшение панели лога в клиенте
- **Коммит:** `feat: death handling and safety stops`

## День 10 — Полировка и релиз v2.2.0 🔧
- Обновление README (новые возможности), актуализация SETUP
- Финальная проверка, тег `v2.2.0` → CI собирает релиз автоматически
- **Коммит:** `release: v2.2.0`
